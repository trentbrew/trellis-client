🔍 Implementation Details

Extension Registration (lines 346-366):

const exts = [
  StarterKit.configure({ ... }),

  Highlight.configure({ multicolor: true }),  // Background highlights
  ...
]

Color Application:

// Set text color
editor.chain().focus().setColor('oklch(0.63 0.21 25)').run()

// Remove text color
editor.chain().focus().unsetColor().run()

// Toggle highlight
editor.chain().focus().toggleHighlight({ color: 'oklch(0.85 0.08 25 / 0.3)' }).run()

// Remove highlight
editor.chain().focus().unsetHighlight().run()

Active State Detection:

// Check if color is active
editor.isActive('textStyle', { color: 'oklch(0.63 0.21 25)' })

// Check if highlight is active
editor.isActive('highlight', { color: 'oklch(0.85 0.08 25 / 0.3)' })

// Get current color
editor.getAttributes('textStyle').color
