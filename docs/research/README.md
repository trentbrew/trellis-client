# Filegraph Paper

This directory contains the draft paper/technical essay documenting Filegraph and the Turtlestack architecture.

## Structure

- `01-introduction.md` - Problem statement, motivation, thesis
- `02-background.md` - Related work and positioning
- `03-architecture.md` - Technical implementation details
- `04-ontology.md` - Ontology design decisions
- `05-implementation.md` - Stack, tradeoffs, realities
- `06-evaluation.md` - What worked, what didn't, lessons learned
- `07-implications.md` - Future work and broader impact
- `08-conclusion.md` - Summary and next steps
- `outline.md` - Full paper outline and notes
- `assets/` - Diagrams, screenshots, figures

## Target Audience

Primary: Builders and hackers who want to understand the architecture and steal ideas

Secondary: Researchers interested in local-first systems, semantic web, AI-native applications

## Publication Plan

1. Draft as long-form technical blog post
2. Get feedback from early users and technical community
3. Refine based on feedback
4. Consider formalizing for arXiv submission

## Writing Guidelines

- Be rigorous but accessible
- Show, don't just tell (use diagrams and code examples)
- Be honest about what didn't work
- Focus on the "why" as much as the "how"
