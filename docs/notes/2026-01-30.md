# Devlog: 2026-01-30

## Tasks Page Improvements

### 1. Folder View Layout - Task Series Handling

**Status:** To Do

Currently, clicking an item in the folder view opens the detail view as if it represents a single task. However, an item actually represents a **series of tasks** (multiple occurrences).

**Options to consider:**

- **Option A:** Add a secondary sidebar to the folder view layout containing all occurrences of the selected task (similar to how the scheduled tasks dialog works)
- **Option B:** Treat items as folders themselves, with child items for each task occurrence

### 2. Scheduled Task Dialog - Tracking Options

**Status:** ✅ Complete

Update the tracking & escalation options from the current 2-option model to the 3-option model:

| Option                  | Description                       |
| ----------------------- | --------------------------------- |
| **Tracked (Corporate)** | Escalates to corporate if overdue |
| **Tracked (Facility)**  | Escalates within facility only    |
| **Untracked**           | No escalation notifications       |

**Reference:** See `TrackedStatus` type in `app/types/ecms/common.ts` which already defines `true | 'facility' | false`

### 3. Custom Fields Simplification

**Status:** ✅ Complete

Simplify custom fields to match the original ECMS app. Required field types:

| Field Type           | UI Component             |
| -------------------- | ------------------------ |
| Text                 | Text input               |
| Long Text            | Textarea                 |
| File Upload          | Image upload             |
| Task Completion Lock | (refer to original repo) |
| Repeating Task Lock  | (refer to original repo) |

**Field configuration schema:**

- `fieldType` (select): text, long text, file upload, task completion lock, repeating task lock
- `fieldName` (text): The display name of the field
- `fieldHelpText` (textarea): Optional help text for the field
